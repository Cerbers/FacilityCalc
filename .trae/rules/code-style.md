1. Use snake_case for variable and function names
2. Use CamelCase for class names and objects
3. Use UPPERCASE for constant names
4. Use indentation of 4 spaces for code blocks
5. Use double quotes for strings
6. Use comments to mark important parts of the code
7. Use docstrings to explain the purpose and usage of classes, functions, and methods  
8. Use type hints to specify the types of function arguments and return values
always apply:
- use dict and list for type hints instead of Dict and List from typing module since they are deprecated and will be removed in future versions of Python
